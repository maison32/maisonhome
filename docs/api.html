Home Guide API

Overview

The maisonhome API exposes a set of endpoints that let you interact with the application programmatically. All responses are returned as JSON.

Base URL

http://localhost:3000/api

Endpoints

GET /status

Returns the current status of the application.

Parameter Type Required Description
No parameters

Example response:

{
  "status": "ok",
  "version": "1.0.0"
}

GET /items

Returns a list of all items.

Parameter Type Required Description
limit integer No Maximum number of items to return (default: 20).
offset integer No Number of items to skip (default: 0).

Example response:

{
  "items": [
    { "id": 1, "name": "Item One" },
    { "id": 2, "name": "Item Two" }
  ],
  "total": 2
}

POST /items

Creates a new item.

Field Type Required Description
name string Yes The name of the new item.

Example request body:

{
  "name": "New Item"
}

Example response:

{
  "id": 3,
  "name": "New Item"
}

Error responses

All errors follow a consistent shape:

{
  "error": "Not Found",
  "message": "The requested resource could not be found.",
  "status": 404
}
